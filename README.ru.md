## 🏪 Liqun Public Proxy - Общедоступная подписка Liqun

Добро пожаловать в **Liqun**. Этот проект предоставляет стабильные, высокоскоростные и постоянно бесплатные общественные сетевые подписки на основе технологии граничных вычислений Cloudflare.

## 🚀 Особенности проекта

  - **Поддержка основных клиентов:** совместимость с ядрами Mihomo, xray и Sing-box.
  - **На базе Cloudflare:** построено на высокопроизводительных решениях Cloudflare, баланс скорости и стабильности, с оптимальными доменами и оптимальными IP-адресами.
  - **В данный момент проект использует Cmliu edgetunnel**

-----

## 📥 Адрес подписки

* **Получение адреса подписки:** Подпишитесь на канал «Liqun» выше, следите за информацией о подписке (обычно в закреплённых сообщениях). Или вступите в группу и отправьте слово "подписка", чтобы получить больше адресов.
* **Получение файла конфигурации Mihomo:** **[📄 Шаблон конфигурации Liqun](/src/liqun_example.yaml)**，регулярно оптимизируется и обновляется, можно сделать fork для отслеживания лучших практик.
