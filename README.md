## 🚀 本项目亮点

  -  **永久固定：** 订阅链接长期有效，一次导入，终身自动更新。
  -  **主流支持：** 深度适配 Mihomo、xray、Sing-box内核为代表的主流代理客户端。
  -  **Cloudflare赋能：** 基于 Cloudflare 高性能开源方案搭建，兼顾速度与稳定性。
  -  **全协议覆盖：** 提供自适应转换，自动转换为各客户端支持的订阅格式。
  -  **本项目当前使用Cmliu edgetunnel 搭建**

> [!TIP]  
> ### 🎯 配置文件特点
>
> #### 1. 按国家分组，结构清晰
>
> 节点自动按国家归类——**香港、日本、韩国、美国、新加坡、台湾省**各成一列，其余节点归入「其他节点」。用户可直接选择目标国家的节点分组，无需在大量节点中逐一辨识。
>
> #### 2. 国内直连 + 国外代理，自动分流
>
> 规则集开箱即用：访问国内站点自动走直连，不影响本地访问速度；访问境外站点自动走代理节点，无需手动切换。广告及隐私域名在请求阶段即被拦截，有效减少无效流量。
>
> #### 3. 每组内置自动优选
>
> 每个国家分组均配有**自动选择**子组，系统通过实时延迟测速自动选取当前最优节点。用户亦可手动固定特定节点，兼顾自动化与灵活性。
>
> #### 4. 四重兜底策略
>
> - **自动选择**：系统实时测速，自动选用延迟最低的节点
> - **手动选择**：用户从全量节点中自行指定
> - **负载均衡**：多节点并发使用，均衡分配流量
> - **故障切换**：当前节点不可用时自动切换至可用节点
>
> 上述兜底策略共同保障连接的高可用性，日常使用无需频繁干预。
>
> #### 5. 无 DNS 泄露
>
> 国内域名使用国内 DNS（阿里云、腾讯云）通过直连解析，境外域名使用公共 DNS 通过代理解析，二者严格隔离。FakeIP 模式进一步将真实 IP 隐藏在内核层，避免 DNS 查询绕过代理泄露用户位置信息。经实际验证，配置不存在 DNS 泄露风险。
>
> * 🔥🔥🔥 详细规则清单请查看 → **[📄 分流规则详解](/src/README.md)**
